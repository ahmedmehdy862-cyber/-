## ترتيب التنفيذ والاعتماديات

`Phase 2` قبل `Phase 3` (الحوار السريع يحتاج النوع الافتراضي)، و`Phase 4` قبل `Phase 5` (الصلاة تستخدم المحرك نفسه).
`Phase 6` و`Phase 7` مستقلتان ويمكن تأجيلهما بلا أثر على بقية المراحل.

## معايير القبول لكل خطوة

1. `./gradlew :app:assembleRelease` ناجح بلا تحذير جديد.
2. `adb install -r` ناجح، والتطبيق يفتح على بيانات المستخدم القائمة دون فقدان.
3. السيناريو المُعدَّل يُمشى يدويًا على الجهاز ويُسجَّل ناتجه هنا.
4. لا تُزال وظيفة قائمة، ولا يظهر نص عاميّ جديد.
5. أي رجوع/إيقاف يُركّب على `BackHandler` المركزي.

## مخاطر معروفة

- MIUI: تحذير إذن «إمكانية الوصول» يظهر عند التفعيل؛ يجب ألا يُقاطع تدفّق الجلسة.
- قيود الخلفية تقتل التذكيرات: يلزم استثناء البطارية وإعادة الجدولة عند الإقلاع.
- الصفوف الكبيرة في `MainActivity.kt` تجعل التعديلات عرضة للتعارض: تُعدَّل بأدوات ذات تأكيدات (asserts) وتُراجَع بالبناء.
