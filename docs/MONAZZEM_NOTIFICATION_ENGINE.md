# محرك التذكير في مُنظِّم (0.16.0)

## الفكرة
بدل تنبيه واحد كل ساعتين لا يعرف سببه، لكل مهمة تذكير محسوب، ولكل قرار سبب ظاهر:
`Send` أو `Defer(until, reason)` أو `Drop(reason)`.

## الملفات
| الملف | الدور |
|---|---|
| `NotificationPolicy.kt` | القرار النقي: بلا Android، قابل للاختبار والشرح |
| `ReminderEngine.kt` | الجدولة والتسليم وأزرار الإشعار والقنوات |
| `PrayerWindows.kt` | نوافذ الصلاة وهامشها وساعات الهدوء |
| `Voice.kt` | صياغة نص الإشعار حسب النبرة والشخصية |
| `StudyDb` (v8) | جدولا `reminders` و`notification_log` |

## ترتيب القواعد (الأول يفوز)
1. الإشعارات موقوفة → `Drop(DISABLED)`.
2. تأجيل طلبه المستخدم → `Defer(SNOOZED)`.
3. جلسة تركيز جارية → `Defer(ACTIVE_SESSION)` وينتهي الأمر بملخص بعد الجلسة (حتى للتنبيه الحرج).
4. داخل نافذة صلاة (افتراضيًا 20 دقيقة قبل و20 بعد) → `Defer(PRAYER)` لنهاية النافذة.
5. داخل ساعات الهدوء (افتراضيًا 23:00–07:00) → `Defer(QUIET_HOURS)` لبداية اليوم.
6. التنبيه الحرج (موعد بعد ≤ 15 دقيقة أو امتحان خلال 24 ساعة) → `Send` خارج الميزانية والحد الأدنى.
7. تجاهل 3 تنبيهات متتالية → `Drop(IGNORED_STREAK)`.
8. استهلاك ميزانية اليوم (هادئ 3 / متوازن 5 / نشيط 8) → `Drop(DAILY_BUDGET)`.
9. أقل من 45 دقيقة منذ آخر تنبيه غير حرج → `Defer(MIN_GAP)`.

## ما يُسجَّل
- `reminders`: موعد كل تذكير وحالته (`pending` / `fired` / `deferred` / `dropped` / `skipped`)، ويُعاد بناؤه بعد الإقلاع وتغيّر الوقت وأي تعديل على المهام.
- `notification_log`: النوع، وقت الجدولة، وقت التسليم، وإجراء المستخدم (`done` / `snoozed` / `snoozed_prayer`)، ومنه تُحسب الميزانية والحد الأدنى وسلسلة التجاهل.

## أزرار الإشعار
«تمّ» يحوّل المهمة إلى منجزة دون فتح التطبيق، و«أجّل ساعة» يحرّك الموعد ساعة (`original_due_at` يبقى محفوظًا)، و«ابدأ تركيز» يفتح إعداد جلسة المهمة عبر `EXTRA_TASK_ID`.

## القنوات
`tasks_v2` و`exams` و`session_summary` — قنوات جديدة لأن أهمية القناة لا تتغير بعد إنشائها. القناة القديمة `task_reminders_mandatory` تبقى، وتبقى الرسائل الصباحية/المسائية كما هي.

 منذ 0.28.0، أصوات قنوات `AppNotifications` (الصلاة، المهام، الامتحانات، الفريق، التحديثات، التشجيع، الأذكار) قابلة للتغيير من لوحة الإدارة دون تغيير معرّف القناة أو أهميتها: تُقرأ الاختيارات من `/api/messages` مع الرسائل، وتُحفظ محليًا، ويُعاد تطبيقها على القناة قبل كل إشعار. الخيار `silent` يُبقي الاهتزاز ويوقف الصوت.

## الوضع الكلاسيكي
مفتاح «التنبيهات الكلاسيكية» في تخصيص التجربة يعيد تذكير الساعتين (9–21) بالضبط كما كان؛ وإيقاف «التذكيرات الذكية» يوقف المحرك الجديد ويعيد القديم.
