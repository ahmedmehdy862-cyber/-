# مكامن — اختبار مكامن القوة

موقع ثابت (static) لاختبار عربي أصلي يرتّب ٣٤ مكمنًا من مكامن القوة ويُظهر أعلى خمسة لديك.
لا خادم ولا قاعدة بيانات: كل شيء يعمل في المتصفح، والإجابات لا تغادر جهاز المستخدم.

## المحتوى

- `index.html` — الصفحة الوحيدة (بطل، أسئلة، نتائج).
- `css/style.css` — الأنماط (RTL، خط Zain للعناوين وNoto Sans Arabic للنصوص من Google Fonts).
- `js/data.js` — المكامن الـ ٣٤ (أسماء ووصف أصلي) و١٠٢ عبارة تقييم.
- `js/app.js` — تدفق الأسئلة، الحساب، المشاركة عبر رابط `#r=...`.

## آلية الاختبار

- ٣ عبارات لكل مكمن (٣٤ × ٣ = ١٠٢)، بمقياس خماسي (١–٥).
- مجموع كل مكمن من ٣ إلى ١٥، والترتيب تنازلي؛ التعادل يُحسم بأسبقية المكمن في القائمة.
- النتيجة تُرمَّز في رابط قابل للمشاركة، والتقدم يُحفظ محليًا (localStorage) للاستئناف.

## ملاحظة قانونية

المحتوى أصلي بالكامل وغير تابع لشركة Gallup أو اختبار CliftonStrengths.
لا تعيد استخدام أسماء أو أسئلة أو نصوص Gallup في أي تعديل.

## النشر على Vercel (مجانًا)

1. أنشئ مستودعًا جديدًا على GitHub وادفع إليه هذه الملفات:
   ```bash
   git init
   git add .
   git commit -m "makamin: initial release"
   git remote add origin https://github.com/<اسمك>/makamin.git
   git push -u origin main
   ```
2. في [vercel.com](https://vercel.com) اختر **Add New → Project** واستورد المستودع.
3. لا يوجد بناء: اترك Framework Preset على **Other**، وحقول Build/Output فارغة.
4. اضغط **Deploy** — يعمل الموقع فورًا على رابط `*.vercel.app` مجاني.

## بديل: GitHub Pages

ادفع الملفات إلى مستودع، ثم من **Settings → Pages** اختر الفرع `main` والمجلد `/ (root)`.
سيعمل الموقع على `https://<اسمك>.github.io/makamin/`.

## بديل أسرع للتجربة

من لوحة Vercel اختر **Add New → Project → Deploy without Git** واسحب مجلد المشروع كاملًا.

## التشغيل محليًا

يكفي فتح `index.html` في المتصفح، أو:
```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```
